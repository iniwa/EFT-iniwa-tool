# v3.4.1 UNTAR Control のモディファイアを追加

🧬 Modifier タブの「シーズン」から「UNTAR Control — Season 2」を選べるようになりました。[Modifier ビルダー](https://efttool.iniwach.com/season-builds)

- 全体モディファイア6種、個人のプラス効果31種、マイナス効果25種を収録しました。
- 個人モディファイアを選ぶと、獲得・消費ポイントと残高を確認できます。ポイント収支はシーズン1と同じルールで試算します。
- 下書きとプリセットはシーズンごとに保存されます。共有リンクは対応するシーズンで開き、下書きへ反映する前にプレビューできます。これまでのシーズン1の共有リンクも使えます。

**シーズン2の内容は、2026年11月19日の公式発表に基づく未確定情報です。** 効果やポイントはシーズン開始前に変更される可能性があります。ゲーム内の表示を優先してください。[Escape from Tarkov 公式発表](https://t.me/escapefromtarkovEN/7003)
